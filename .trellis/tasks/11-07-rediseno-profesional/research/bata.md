# Research: Bata Colombia (bata.com/co)

- **Scope**: external · **Date**: 2026-11-07 · **Method**: built-in browser (DOM text + one small screenshot). Cookie banner left untouched (not accepted).
- **Confidence**: medium-high. Most relevant brand: a family shoe store selling in Colombia, like Leidy Carolina.

## Findings
1. **Header**: thin top bar with sub-brands; announcement line about the exchange window (up to 30 days for changes); centred red wordmark; hamburger + search on the left, account / wishlist / cart icons on the right; mega-menu.
2. **Taxonomy**: Mujer / Hombre / Infantil (Niña, Niño). Types under each: Tenis moda, Tenis deportivos, Sandalias, Botines, Botas, Baletas, Tacones, Mocasines, Chanclas, Zapatos formales, Outdoor, Zapatos de seguridad. Plus "Nueva colección", "Ofertas", accessories, and kids collections by theme (tenis con luces, licensed characters).
3. **Listing**: 6-column grid track on desktop; card shows brand line, name, colour, crossed "before" price, sale price and a red "-80%" badge, and an "Agregar al carrito" button. Price format "Col$ 129.900,00".
4. **Home**: full-width hero carousel with 3 red rectangular buttons (Zapatos / Accesorios / Ver T&C), "Recomendados para ti" product carousel.
5. **Visual**: white ground, black text, brand red only for logo, buttons and discounts; square corners; DM Sans.

## Adoptable for Leidy Carolina (ranked)
1. Family taxonomy with types under each gender, kids split into Niña / Niño.
2. "Before / now" price + "-X%" badge when a model is on sale (optional data field).
3. Announcement line for the exchange policy (only once the owner confirms it).
4. Kids theme collections (e.g. "Tenis con luces") as type pills.
5. One brand colour used only for actions and discounts.
